문의 전에 확인해 주세요

사용 중인 휴대전화 종류, 앱 버전, 문제가 발생한 화면과 상황을 알려주시면 확인에 도움이 됩니다.

비밀번호는 문의 내용에 포함하지 마세요. 비밀번호를 잊으셨다면 사용 중인 아이디와 함께 계정 확인을 요청해 주세요.

자주 묻는 질문

처음 로그인했는데 로봇이 보이지 않아요.

앱의 로봇 연결 버튼에서 지원 기체를 추가하거나 관리자에게 기체 할당을 요청하세요. 새 계정에는 기체가 자동으로 할당되지 않습니다.

Android에서 로봇을 연결하려면 어떻게 하나요?

로봇을 켜고 휴대전화의 Wi-Fi와 위치 서비스를 켜세요. 앱에서 로봇 연결을 누른 뒤 필요한 권한을 허용하고 검색된 기체를 선택해 추가하세요. 기체 Wi-Fi 이름 끝의 -5G와 -2.4G는 같은 기체로 표시됩니다.

iPhone에서 로봇 Wi-Fi를 찾으려면 어떻게 하나요?

로봇 전원을 켜고 인터넷이 연결된 상태에서 앱의 로봇 연결 화면을 여세요. iOS 18 이상과 Farmily 1.0.0(4) 이상에서는 주변 로봇 찾기를 누르면 Apple 기기 선택창이 열립니다. 선택한 기체가 앱 목록에 표시되면 체크한 뒤 추가하세요. 여러 대는 한 대씩 선택해 목록에 모을 수 있습니다. 선택창에 기체가 보이지 않거나 이전 iOS를 사용하는 경우 iPhone 설정 → Wi-Fi에서 로봇 Wi-Fi에 연결한 뒤 앱의 현재 Wi-Fi 확인을 사용하세요. 이 대체 방법에는 위치 접근과 정확한 위치 허용이 필요합니다. 앱이 주변의 일반 Wi-Fi 전체 목록을 받지는 않습니다.

로봇 Wi-Fi에 연결하면 인터넷이 끊겨요.

로봇 Wi-Fi 확인 후 인터넷이 가능한 Wi-Fi나 모바일 데이터로 돌아와 추가하세요. 앱에서 확인한 기체 목록은 잠시 유지됩니다. 추가가 완료되면 인터넷으로 기체 상태와 작업 이력을 확인할 수 있습니다.

권한을 허용하지 않아도 앱을 사용할 수 있나요?

네. 알림과 로봇 연결용 위치 권한은 선택 사항입니다. 권한을 거부해도 로그인과 이미 할당된 기체 조회는 이용할 수 있습니다. 로봇 연결 시 위치 좌표를 수집하지 않습니다.

계정과 개인정보를 삭제하고 싶어요.

앱의 계정 관리 → 회원 탈퇴 또는 웹 회원 탈퇴를 이용하세요. 본인 계정과 해당 계정의 기체 연결 정보가 삭제됩니다. 공용 기체 운행 기록과 다른 사용자의 정보는 유지됩니다.
