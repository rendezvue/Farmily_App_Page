Farmily 앱의 제품 소개, 고객지원, 개인정보처리방침, 회원 탈퇴 안내를 제공합니다.

- 제품 소개: https://rendezvue.github.io/Farmily_App_Page/
- 고객지원: https://rendezvue.github.io/Farmily_App_Page/support.html

## 게시

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다.
별도 빌드 도구는 필요하지 않습니다. `.nojekyll` 파일을 유지하세요.

이 저장소에는 공개 HTML, 스타일과 브랜드 이미지 파일만 포함합니다.
로그인 입력창, 사용자 데이터, 비밀번호, 운영 환경 파일, 서버 키 또는 앱 소스를
추가하지 마세요. 회원 탈퇴의 본인 확인과 처리는 별도 Farmily 서버에서 수행합니다.

정책을 바꾸면 앱에서 표시하는 정책과 공개 페이지를 함께 갱신하세요.
