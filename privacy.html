Farmily 개인정보처리방침
시행일: 2026년 11월 12일

1. 처리 목적과 항목
Farmily는 회원가입·로그인, 사용자별 기체 조회 및 작업 알림을 위해 아이디, 사용자 이름, 비밀번호 해시, 가입 시각, 할당된 기체 ID를 저장합니다. 비밀번호 원문은 저장하지 않습니다. 로그인 토큰과 선택한 기체·언어 설정은 앱 기기에 저장됩니다.

2. Wi-Fi와 위치 권한
로봇 연결을 누른 경우에만 Wi-Fi 검색 또는 현재 연결된 Wi-Fi 이름 확인에 필요한 권한을 요청합니다. Android는 주변 Wi-Fi를 확인합니다. iOS 18 이상에서는 Apple의 기기 선택창으로 FMLY- 이름의 로봇을 찾고 사용자가 선택한 기체만 앱에 전달받습니다. 선택창은 위치 권한을 요구하지 않습니다. 이전 iOS 버전이나 대체 연결 방법에서는 현재 연결된 Wi-Fi 이름을 확인하며 정확한 위치 권한이 필요합니다. 위치 좌표는 수집하지 않으며, 주변의 일반 Wi-Fi 이름이나 검색 목록은 서버에 보내거나 저장하지 않습니다. 선택한 등록 기체 ID만 서버로 전송합니다. 권한을 거부해도 관리자가 할당한 기체는 사용할 수 있습니다.

3. 알림 및 외부 서비스
운영자 (주)랑데뷰는 회원 데이터베이스와 운영 백업을 대한민국 내 자체 관리 서버에 보관합니다. 기체 상태와 작업 이력은 기체에서 수집되며 할당된 사용자에게 제공됩니다.
작업 푸시 알림은 Google Firebase Cloud Messaging을 사용합니다. 알림 전달을 위해 앱 설치 식별자·알림 토큰, 사용자별 알림 구독 식별자, 기체 ID와 작업 상태가 처리됩니다. Google의 글로벌 인프라를 통해 국내외에서 처리될 수 있으며, 국내 자체 서버 보관과는 별개의 처리입니다. 알림 권한은 기기 설정에서 변경할 수 있습니다.
작업 이메일과 고객지원 메일에는 Microsoft 365를 사용합니다. 작업 이메일은 Microsoft Graph를 통해 지정된 수신자에게 전송되며 수신자 이메일 주소, 기체 ID, 작업 상태·시각, 이메일 본문이 처리됩니다. 고객지원 문의 시에는 발신자 이메일 주소와 문의 내용이 처리됩니다. 실제 저장·처리 위치는 Microsoft 365 계약과 조직 설정에 따릅니다. 비밀번호는 이메일 문의에 포함하지 마세요. 광고 목적으로 개인정보를 판매하지 않습니다.
공개 제품 소개·고객지원·개인정보처리방침·탈퇴 안내 웹사이트는 GitHub Pages에서 제공합니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관하며, 공개 개인정보처리방침에 따라 미국 등 서비스 운영 지역에서 정보를 처리할 수 있습니다. Farmily는 이 안내 사이트에 분석 도구, 광고 또는 로그인 입력창을 넣지 않습니다. 회원 데이터베이스, 비밀번호, 기체 할당과 로봇 작업 이력은 이 공개 웹사이트에 게시하거나 이전하지 않습니다. 실제 회원 탈퇴는 국내 자체 서버로 이동한 후 처리합니다. GitHub의 처리 및 보관 기준은 https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 를 참고하세요.

4. 보유 및 삭제
회원 정보는 서비스 이용 중 보유하며, 회원 탈퇴 완료 시 운영 데이터베이스에서 계정과 해당 계정의 기체 할당을 삭제합니다. 앱에서 탈퇴하면 현재 기기의 로그인 정보를 제거합니다. 다른 기기에서도 이후 서버 요청 시 해당 계정으로 접근할 수 없습니다.
국내 자체 서버의 정기·배포 백업은 생성 후 30일, 앱 서버와 앱 웹사이트의 오류·진단 로그는 기록 후 30일 보관하고 기간이 지난 파일을 자동 정리합니다. 오류·진단 로그에는 발생 시각, 오류 유형과 기술적 진단 내용이 포함되며, 웹 서버 오류에는 접속 IP가 포함될 수 있습니다. 로그는 일 단위 파일로 관리하므로 해당 날짜의 마지막 기록까지 보관 기간을 충족한 뒤 정리합니다. 백업에 남은 탈퇴 정보는 백업 만료 시 삭제되며, 백업 복원 시 탈퇴 처리를 다시 반영한 후 서비스를 재개합니다.
관리자 접속기록은 보안 점검과 개인정보 접근 추적을 위해 1년 보관 후 자동 정리합니다. 관리자 식별자, 접속 시각·IP, 수행 업무, 처리 대상 계정·기체 식별자, 처리 결과를 기록하며 비밀번호나 로그인 토큰은 기록하지 않습니다. 위 기간은 자체 서버의 운영 백업·로그에 적용되며 외부 서비스가 처리하는 식별자·메일의 보관 기간과는 구분됩니다.
로봇 작업 이력 원본과 작업 중단 사유 등 업무 기록은 위 30일·1년 자동 삭제 대상이 아닙니다. 회원 탈퇴나 로그 정리로 다른 사용자의 계정·할당과 공용 기체의 운행 기록을 삭제하지 않습니다. 법령에 따른 별도 보관 의무가 있는 경우 해당 범위와 기간에 한하여 보관합니다.

5. 이용자의 권리
앱의 계정 관리 → 회원 탈퇴 또는 https://lab.farmily.ai:241/account-deletion 에서 아이디와 비밀번호로 본인 확인 후 탈퇴할 수 있습니다. 계정 정보 열람·정정 및 개인정보 문의는 아래 연락처로 요청할 수 있습니다.

6. 보호 조치 및 권한 선택
비밀번호는 단방향 해시로 저장합니다. 운영 앱과 서버 간 개인정보 전송에는 HTTPS를 사용합니다. 계정 조회·할당 관리에는 서버의 사용자·관리자 권한 검사를 적용합니다. 알림 권한과 로봇 연결용 Wi-Fi 확인 권한은 해당 기능을 위한 선택 권한이며, 거부해도 로그인과 이미 할당된 기체 조회를 이용할 수 있습니다. 기체는 Wi-Fi 이름으로 직접 추가할 수 있으므로 기체 할당이 독점적인 소유권을 뜻하지 않습니다.
